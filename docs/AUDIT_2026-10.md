# Audit, October 2026: can this server capture a SOM carrier schematic?

Target: the AMD Kria K26 CubeSat payload carrier (hierarchical sheets, a
480-pin SOM connector, 50 ohm / 90 ohm nets, BOM with MPN / manufacturer /
radiation grade). Environment: KiCad 10.0.1 (macOS), Python 3.10, branch
`fix/schematic-grid-fields` as the starting point (`efdcc21`).

Method: build real projects through the tool layer, then let `kicad-cli`
judge them (`sch erc`, `sch export netlist`, `sch export bom`,
`sch upgrade`). Pin positions, connectivity and net classes were checked
against the netlist KiCad writes, not against our own reading of the file.

## KiCad 10 compatibility

- Files written with `(version 20250114)` load in KiCad 10; `kicad-cli sch
  upgrade` rewrites them as `20260306` without complaint. The README divider
  and a 4-sheet hierarchy give a correct netlist and no load error.
- All four rotations of a symbol put pins where `list_pins` says (checked by
  labelling every pin and reading the netlist), for single- and multi-unit parts.
- `run_erc` / `run_drc` / `export_netlist` / `export_bom` work. ERC text is
  localised (Spanish here); only the `type` keys are stable, which is what the
  code uses.
- PCB path (`update_pcb_from_schematic`, DRC) is covered by the existing
  phase 5/7/10 tests against real `kicad-cli`; not re-probed with the carrier.

## Limitations the schematic work must plan around

- **Set the paper first.** `set_sheet_paper` refuses a sheet that already has
  content. A 60-row unit needs A3 at least; A1 or `User` for the whole SOM sheet.
- **Grid.** Symbol origins on multiples of 2.54 mm keep 1.27 mm pin offsets on
  the connection grid. Results carry `warnings` when something is off-grid.
- **ERC cannot count pins.** KiCad 10.0.1's ERC skips a few percent of floating
  pins in a dense symbol (position-dependent, deterministic). Use a netlist
  export for pin completeness.
- **Net names.** Local labels are `/NAME` or `/sheet/NAME`; only global labels
  and power symbols are bare. Cross-sheet nets: global labels, or hierarchical
  label + `sync_sheet_pins` + `label_sheet_pins`.
- **Bus entries and members** were drawn and ERC-checked, but connectivity in
  our probes came from per-wire labels; bus-member semantics (`D[0..7]`) are
  not independently verified.
- **One sheet level** below the root (defect 19).
- **Vendor symbols** keep whatever else their authors wrote; only the datasheet
  is normalised. Check imports with `run_erc` for `lib_symbol_mismatch`.
- `uv run pytest` needs `kicad-cli`; the Freerouting acceptance test needs
  `third_party/freerouting.jar` (not downloaded here).
